# Student Performance Management System 🚀

A comprehensive Python-based analytical tool designed to streamline, calculate, and manage academic performance data for undergraduate students.

## Key Features 🌟
- **Automated Grade Analysis:** Dynamically processes percentage scores to assign standardized global academic grades (A+, A, B, C, Pass/Fail).
- **Error & Exception Handling:** Structured using robust `try-except` blocks to prevent crashes from invalid user inputs (non-numeric values).
- **Clean Command Line Interface:** Interactive terminal interface designed for quick and seamless data processing.

## Technical Skills Demonstrated ⚙️
- **Programming Language:** Python 3
- **Core Concepts:** Functions, Conditional Logic, Dynamic Typecasting (`float`), and Robust Exception Handling (`ValueError`).
